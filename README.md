# موقع مدرسة شهيد حسن حمدي + لوحة تحكم أدمن

## هيكل الملفات
```
/index.html        ← الصفحة نفسها (HTML بس)
/css/style.css      ← كل التنسيقات (كان قبل كده جوه <style> في نفس الملف)
/js/site.js          ← كود الموقع العادي (المدرسين، الطلاب، الصفحات، الأنيميشن...)
/js/admin.js         ← كود لوحة الأدمن بس (منفصل تمامًا عن كود الموقع)
/api/                ← دوال السيرفر (Vercel functions) اللي بتكلم قاعدة البيانات
/schema.sql
/package.json
/README.md
```
كل حاجة كانت متكدسة في ملف HTML واحد بقت متقسمة على حسب نوعها. `js/site.js`
لازم يتحمّل قبل `js/admin.js` لأن admin.js بيستخدم بعض الدوال اللي في site.js —
الترتيب ده متظبط بالفعل جوه `index.html`، متغيّرهوش.

## اللي اتعمل
- الموقع الأصلي زي ما هو بالظبط (نفس التصميم والحركات)، بس بقى بيقرأ المدرسين
  والطلاب والصور من قاعدة بيانات بدل ما تبقى مكتوبة جوه الكود.
- لو قاعدة البيانات لسه مش متوصلة أو حصل خطأ، الموقع بيرجع تلقائيًا للبيانات
  الافتراضية الموجودة في الكود عشان الموقع متعطلش أبدًا.
- لوحة أدمن **مخفية تمامًا** — مفيش أي زرار أو لينك ليها في الموقع. بتتفتح بس
  لو حد كتب بنفسه `/#/admin` في آخر الرابط.
- من لوحة الأدمن تقدر: تضيف/تعدل/تمسح مدرسين، تضيف/تعدل/تمسح طلاب أوائل،
  وتضيف/تمسح صور ذكريات — وكل حاجة بترفع للموقع فورًا لأي زائر.
- الدخول للوحة محمي بكلمة سر واحدة (مش يوزر باسورد كامل، بس كافي لموقع مدرسي
  بسيط). كل طلب تعديل بيتأكد من كلمة السر على السيرفر نفسه.

## خطوات الرفع (من الصفر لحد الموقع شغال)

### 1) قاعدة البيانات (Neon)
1. سجل في https://neon.tech وأنشئ مشروع جديد (Database).
2. من الـ SQL editor بتاعهم، افتح ملف `schema.sql` من المشروع ده وشغّله مرة واحدة
   (بينشئ 3 جداول: teachers, students, photos).
3. من صفحة الـ Connection String، انسخ الرابط اللي شكله:
   `postgresql://user:pass@ep-xxxx.neon.tech/dbname?sslmode=require`
   — ده هو اللي هنحطه في `DATABASE_URL`.

### 2) GitHub
1. اعمل ريبو جديد وارفع كل ملفات المشروع ده فيه (index.html, api/, package.json,
   schema.sql, .gitignore...) — **متضيفش** ملف `.env` لو عملته، خليه بس عندك محليًا.

### 3) Vercel
1. سجل في https://vercel.com وقول "Add New Project" واختار الريبو اللي رفعته.
2. Vercel هيكتشف الملفات تلقائيًا (مفيش build step مطلوب، الموقع static + api/).
3. قبل الديبلوي (أو بعده من Settings -> Environment Variables) ضيف:
   - `DATABASE_URL` = رابط Neon اللي نسخته فوق
   - `ADMIN_PASSWORD` = كلمة سر قوية من اختيارك (احفظها كويس، هي مفتاح اللوحة)
4. اعمل Deploy. بعد ما يخلص، هيديك رابط زي `your-school.vercel.app`.

### 4) الدخول للوحة الأدمن
افتح: `https://your-school.vercel.app/#/admin`
وادخل بكلمة السر اللي حطيتها في `ADMIN_PASSWORD`.

## ملاحظات مهمة
- **كلمة سر الأدمن**: احفظها في مكان آمن. أي حد يعرفها يقدر يتحكم في الموقع
  بالكامل. لو حسيت إنها اتسربت، غيّرها من Environment Variables في Vercel
  وهتشتغل فورًا من غير أي تعديل في الكود.
- **الصور**: بتتخزن كـ base64 جوه قاعدة البيانات نفسها (مفيش خدمة تخزين ملفات
  منفصلة)، والفرونت بيصغّر أي صورة ترفعها تلقائيًا (لحد ~900px) قبل الرفع عشان
  تفضل قاعدة البيانات خفيفة. ده كويس لعدد صور معقول (كام مية)، لو حبيت تحط آلاف
  الصور يبقى الأفضل بعدين ننقل التخزين لـ Vercel Blob بدل قاعدة البيانات.
- **بيانات المدرسين والطلاب القدام**: البيانات اللي كانت مكتوبة جوه الكود قبل
  كده لسه موجودة كـ "بيانات احتياطية" (DEFAULT_TEACHERS / DEFAULT_STUDENTS) —
  الموقع بيعرضها لحد ما تضيف بيانات حقيقية من لوحة الأدمن، وبعدين بيعرض بيانات
  قاعدة البيانات تلقائيًا.
